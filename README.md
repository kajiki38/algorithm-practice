# アルゴリズム道場

手を動かして学ぶアルゴリズム学習サイト。ビルド不要・依存ライブラリなしの静的サイトです。

## Pages
https://kajiki38.github.io/algorithm-practice/

## 使い方

`index.html` をブラウザで開くだけで動きます。

```
start index.html        # Windows
```

ローカルサーバー経由で開く場合:

```
python -m http.server 8000
# → http://localhost:8000 を開く
```

## コンテンツ（おすすめ学習順）

まず遊んで「速さの違い」を体感し（STEP 1〜2）、その体験に名前をつけ（STEP 3 計算量）、
道具と応用に進む —— という初学者向けの並びです。

| STEP | ページ | 内容 | ハンズオン要素 |
|---|---|---|---|
| 1 | `search.html` | 二分探索 | 数当てゲーム・手動での二分探索操作・線形探索との比較 |
| 2 | `sorting.html` | ソート 7 種の可視化 | ステップ実行・擬似コード追跡・アルゴリズム当てゲーム |
| 3 | `complexity.html` | 計算量（Big-O） | 体験→記号の対応表・成長曲線グラフの操作・計算量当てクイズ 12 問 |
| 4 | `datastructure.html` | スタック・キュー・ハッシュ | push/pop 操作・取り出し順の予想クイズ・衝突の可視化 |
| 5 | `recursion.html` | 再帰・分割統治 | ハノイの塔（手動 + 自動解答）・fib 呼び出しツリー |
| 6 | `dp.html` | 動的計画法 | コイン両替の表埋め・セル当てクイズ・0/1 ナップサック |
| 7 | `strings.html` | 文字列探索 | 総当たり / KMP の 1 比較ずつ再生・対決モード |
| 8 | `pathfinding.html` | BFS / DFS / ダイクストラ / A* / 貪欲法 | 迷路づくり（壁・沼）・5 手法の一括比較 |
| 9 | `python.html` | Python 実践 | ブラウザ内で実行・自動採点される問題 12 問 + プレイグラウンド |

経路探索のグリッドはマウスドラッグのほか、キーボードでも操作できます
（グリッドにフォーカス → 矢印キーで移動、Enter / Space でツール適用）。

ヘッダー右端のボタンでライト/ダークテーマを切り替えられます（既定はライト）。
選択は `localStorage` に保存され、次回訪問時も維持されます。

`python.html` は実行環境（Pyodide）を CDN から読み込むため、初回のみインターネット接続が必要です。

## 構成

```
index.html / *.html      各ページ
css/style.css            共通スタイル（デザイントークン + SVG マスクアイコン）
js/common.js             ナビゲーション・共通ユーティリティ
js/algorithms.js         コアロジック（純粋関数、DOM 非依存）
js/<page>.js             各ページの UI ロジック
tests/run-tests.js       コアロジックのユニットテスト
```

`js/algorithms.js` は UMD 形式で、ブラウザからは `window.Algo`、Node.js からは
`require()` で読み込めます。ソートは「操作列（compare / swap / set …）」を返す
設計で、UI 側はそれを初期配列に適用して任意ステップの状態を再現します
（これにより「1 ステップ戻る」やシークバーが自然に実装できます）。

## テスト

```
node tests/run-tests.js
```

ソート 7 種の正しさ（境界ケース + ランダム）、replay の一貫性、二分探索、MinHeap、
経路探索 5 種（最短性・A* とダイクストラの一致・到達可能性）、ハノイの塔（手数と合法性）、
fib 呼び出しツリーの呼び出し回数、文字列探索（総当たり / KMP の一致・比較回数上限）、
DP（コイン両替・ナップサックの総当たり照合）、ハッシュ関数を検証します。
