ソートアルゴリズム可視化

バラバラの数の列を小さい順に並べ替える「ソート」。 同じ結果にたどり着く方法が 7 種類もあって、それぞれ動き方も速さもまるで違う —— その違いを目で見て楽しむページ。

このページで学ぶこと

ソート（並べ替え）は、コンピュータの世界でいちばんよく使われる処理のひとつ。 検索結果の並び順、ランキング、家計簿の日付順 —— ぜんぶソートだ。 そして STEP 1 で見たとおり、二分探索は「並んでいること」が前提だった。 その「並べておく」を引き受けるのがソート。だからソートはあらゆるアルゴリズムの土台になっている。

下の画面では、棒の高さ = 数の大きさ。バラバラの棒たちが左から右へ低い順に整列していく様子をアニメーションで見られる。 注目してほしいのは動きの美しさだけじゃなく「比較」カウンタ。 同じ 30 本を並べ替えるのに、バブルソートは 400 回以上比較するが、クイックソートは 150 回ほどで終わる。 同じ仕事なのに 3 倍近い差 —— この違いの正体は、次のステップ「計算量」で明かされる。

このページの使い方

  1. 1
    まずバブルソートのまま「再生」を押して、最後まで眺める。緑（確定）が右から積み上がっていく。
  2. 2
    終わったら比較の回数をメモして、アルゴリズムをクイックソートに変えてもう一度。回数の差に注目。
  3. 3
    「1つ進む」で 1 手ずつ送ると、右の擬似コード（プログラムの設計図を日本語混じりで書いたもの）のどの行が動いているかが光る。仕組みを知りたくなったらこれ。
  4. 4
    プリセットを「ほぼ整列済み」や「逆順」に変えると、得意・不得意が逆転するアルゴリズムがある。挿入ソートとクイックソートで試そう。
  5. 5
    仕上げに観察チャレンジ。動きだけでどのソートか当てられたら、かなり見えている。
つまずいたら: 用語ミニ辞典
比較 / 交換
ソートの基本操作。「どっちが大きい？」と見比べるのが比較（オレンジ色に光る）、2 本の棒の場所を入れ替えるのが交換（赤く光る）。この回数が少ないほど速いアルゴリズム。
擬似コード（ぎじコード）
プログラムの手順を、特定の言語にしばられず読みやすく書いたメモのこと。「for i in 0 .. n-2」は「i を 0 から n−2 まで 1 つずつ増やしながら繰り返す」という意味。
配列（はいれつ）
データを 1 列に並べた入れ物。ここでは棒の列そのもの。各位置には 0 から始まる番号（インデックス）が付いている。
ピボット
クイックソートが使う「基準の値」（紫色の棒）。「ピボットより小さい組と大きい組に分ける」を繰り返すのがクイックソート。
安定ソート
同じ値が複数あったとき、元の順番を保ったまま並べ替えるソートのこと。マージソートは安定、クイックソートは不安定。
比較中 交換/書込 ピボット 確定 範囲外
ステップ 0 / 0 比較 0 交換・書込 0

それぞれのアルゴリズムの特徴

    

      表の O(…) は「データが増えたときの手間の増え方」を表す記号（次のステップ「計算量」で学ぶ）。
      今は n² 系 = 遅いグループ、n log n 系 = 速いグループとだけ読めれば十分。
    

    

      
        
アルゴリズム平均最悪特徴

      
      
        
バブルソートO(n²)O(n²)隣同士を比較して交換。最大値が泡のように右端へ「浮かぶ」。実用性は低いが動きが最も分かりやすい。

        
選択ソートO(n²)O(n²)未ソート部分から最小値を「選択」して先頭へ。交換回数は最大 n−1 回で済むのが特徴。

        
挿入ソートO(n²)O(n²)手札のカードを並べる動き。「ほぼ整列済み」データでは O(n) に近くなる。プリセットで試そう。

        
シェルソート≈O(n^1.3)ギャップ列に依存離れた要素同士で挿入ソートし、間隔を詰めていく。挿入ソートの「遠くへ運ぶのが遅い」弱点を克服した改良版。

        
クイックソートO(n log n)O(n²)ピボットで大小に分割して再帰。実測で最速級。ただし「逆順」プリセット + 末尾ピボットでは苦手な形になる。

        
マージソートO(n log n)O(n log n)半分に割って統治(マージ)。どんな入力でも O(n log n) を保証。安定ソート。追加メモリが必要。

        
ヒープソートO(n log n)O(n log n)配列を最大ヒープ(親≥子の木)に組んでから、最大値を末尾へ確定させ続ける。追加メモリ不要で最悪 O(n log n) 保証。
