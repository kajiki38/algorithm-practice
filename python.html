進め方

  1. 1
    問題文を読む。「関数 ○○(…) を書こう」とあるのは、「この名前の処理のかたまりを完成させて」という意味。エディタには途中まで書かれた下書きが入っている。
  2. 2
    エディタの # ここに実装する の部分に自分のコードを書く。行頭の字下げ（スペース 4 つ）が意味を持つのが Python の特徴なので、下書きの字下げに合わせること。
  3. 3
    「テスト実行」を押すと、いろいろな入力で自動チェックされる。✔ と ✘ で結果が出るので、✘ の「期待値」と自分の出力を見比べて直す。間違えても壊れないので何度でも。
  4. 4
    詰まったらヒント 1 → 2 → 3 の順に開く。15 分粘ってダメなら模範解答を見て、写して動かしてから白紙でもう一度書くのが最短の上達法。
Python がはじめての人へ: 最低限の文法メモ
def sum_list(nums):
「sum_list という名前の関数（処理のかたまり）を定義する。nums という材料を受け取る」という意味。関数の中身は字下げして書く。
return x
「答えとして x を返して終わる」。テストはこの返した値をチェックしている。print（画面に表示）とは別物なので注意。
for x in nums:
「nums の中身を先頭から 1 つずつ x に入れて繰り返す」。回数で回すなら for i in range(n):（i が 0, 1, …, n−1 と動く）。
if a < b: / elif / else
「もし a が b より小さいなら…、そうでなくてもし…、どれでもなければ…」の場合分け。
nums[i] / len(nums)
リスト nums の i 番目の要素（0 から数える）/ リストの長さ。nums.append(x) で末尾に追加。
インデント（字下げ）
Python は「どこからどこまでがループや if の中身か」を字下げで表す。エディタでは Tab キーでスペース 4 つが入る。
